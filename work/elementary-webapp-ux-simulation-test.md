# 시뮬레이션 전용 검증 기록

## 판정

`elementary-webapp-ux-simulation-decision.md`의 결정이 `not-needed`이므로 새 시뮬레이션 검증은 N/A입니다. 이 문서는 N/A 사유와 대신 수행한 기존 계산·UI 회귀 범위를 남깁니다.

## N/A 사유

- 시간에 따라 자동 실행되는 상태가 없습니다. `pause`·`step` 불필요.
- 학생이 바꾸는 의미 있는 변수는 새 수치가 아니라 관계 선택과 변화 방향 선택입니다.
- DOM/SVG와 세 단계 라벨이 결과를 정적으로 관찰할 수 있고, Canvas/WebGL 렌더러가 없습니다.
- 생성 이미지는 수치·정답·측정·과학적 증거로 사용하지 않았습니다.

## 대체 회귀 범위

| 검사 | 기준 |
|---|---|
| 관계 복원 | 정답 연결은 성공하고, 역방향·중복·분해자·미션 밖 연결은 회복 문구를 표시 |
| 복원 경계 | 기대 관계를 모두 찾기 전에는 예측 단계로 넘어가지 않음 |
| 예측 경계 | 바로 연결된 생물의 방향을 모두 고르기 전에는 결과로 넘어가지 않음; 건너 연결은 선택 사항 |
| 결과 | 학생 선택과 가상 결과를 구분하고, 영향 거리·근거를 읽을 수 있음 |
| 반응형 | 320×800, 375×812, 1280×900에서 핵심 CTA·표·용어 풀이가 viewport 안에 있음 |
| 접근 가능한 조작 | 마우스 없이 Tab/Enter/Space로 핵심 버튼과 예측 선택지를 조작하고 포커스를 확인 |
| 모션 | `prefers-reduced-motion` 또는 앱 토글에서 펄스·전환이 멈춤 |
