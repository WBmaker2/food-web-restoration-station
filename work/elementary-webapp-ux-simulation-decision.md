# 교육용 인터랙티브 시뮬레이션 결정 장부

## 판정

| 항목 | 결정 |
|---|---|
| 상태 | `not-needed` |
| 대상 학습 목표 | 먹이 관계를 복원하고, 한 생물의 변화가 연결된 생물에 이어지는 방향을 예측하기 |
| 현재 상호작용 | 카드 두 장 선택, 관계 연결, 직접·간접 영향 선택, 결과 비교 |
| 전문 라우팅 | `game-studio:game-studio`·`build-web-data-visualization:data-visualization` 호출 불필요 |
| 이미지 | `no-image-needed` |

## 판정 근거

이 앱의 핵심은 시간에 따라 움직이는 생태계나 연속 수치를 조작하는 것이 아니라, 고정된 관계 그래프에서 한 가지 연결과 방향을 해석하는 것입니다. 현재 DOM/SVG 그래프, 관계 목록, 세 단계 개체 수 라벨만으로 다음 학습 루프를 관찰할 수 있습니다.

```text
단서 읽기 → 관계 연결 → 직접/간접 영향 예측 → 가상 결과 비교 → 생각 수정
```

슬라이더·Canvas·WebGL·물리 엔진을 추가하면 학습 변수가 늘고 모델 경계·키보드·모바일 비용이 커지지만, 현재 목표를 더 분명하게 만들지는 않습니다. 따라서 새 시뮬레이션 엔진은 구현하지 않습니다. 기존 계산 엔진의 결과와 단계형 UI를 명확하게 만드는 것이 우선입니다.

## 모델 경계

- 영향 계산은 실제 자연의 측정·예측이 아니라 이 앱의 가상 초원 관계와 `적음/보통/많음` 세 단계 규칙입니다.
- 시간 흐름이 없으므로 `pause`와 `step`은 N/A입니다.
- 랜덤성·seed·단위·연속 측정값은 사용하지 않습니다.
- 관계 방향·결과 근거는 생성 이미지가 아니라 코드의 데이터·DOM/SVG·텍스트에 둡니다.
- 실제 수업 전에 생물 관계와 단순화 규칙을 교사·교과 담당자가 검토해야 합니다.

## 구현 범위와 대안

- 이번 개선에서 구현하는 것은 시뮬레이션 추가가 아니라 `복원 완료 → 예측 → 결과 비교`의 경계를 분명하게 하는 것입니다.
- 대안으로 관계를 자유롭게 배치하는 Canvas나 시각화 라이브러리를 검토했지만, 현재 SVG/DOM의 접근 가능한 관계 목록으로도 같은 목적을 달성하므로 보류합니다.
- 이미지 생성은 호출하지 않았습니다. 이 화면에서 그림은 관계 정답·수치·과학적 증거를 대신할 수 없고, 이모지 카드와 SVG 선이 현재 학습 행동을 직접 안내합니다.

## 테스트 장부

새로운 시뮬레이션을 구현하지 않으므로 시뮬레이션 전용 게이트는 N/A입니다. 대신 기존 그래프·영향 엔진의 단위 테스트와 실제 UI의 동일 시나리오 회귀를 수행합니다.

- 관계 연결: 정답·역방향·중복·분해자·미션 밖 쌍 피드백
- 영향 결과: 직접·간접·대체 먹이·분해자·미연결 상태
- UI: 320/375/1280px, 키보드 Tab/Enter/Space, reduced-motion CSS, 콘솔·자산 요청
- VoiceOver: 범위에서 제외
