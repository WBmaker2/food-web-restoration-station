이 계획은 2026-08-31 실제 공개 화면 감사와 모의 학습자 패널 결과를 기준으로 작성했으며, 구현 전에 먼저 저장했습니다. 사용자의 승인에 따라 추천안을 순서대로 적용했습니다. 커밋·푸시·배포·HVC 등록은 이번 요청 범위에 포함하지 않아 수행하지 않습니다.

## 1. 제품 목표와 보존할 계약

- `먹히는 생물 → 먹는 생물` 화살표 규칙을 유지합니다.
- 관계 복원과 변화 예측을 점수 게임이 아니라 근거 설명 활동으로 유지합니다.
- 영향 계산은 이 가상 초원의 고정 관계와 `적음/보통/많음` 세 단계 모델로 유지합니다.
- 학생이 찾은 관계와 미션 기준 관계를 구분하되, 기준 답이 복원 전에 노출되지 않게 합니다.
- 서버·로그인·개인정보 저장·외부 폰트 의존성을 추가하지 않습니다.
- 모든 핵심 단계 CTA는 현재 디자인 언어의 `gi-pulse`를 사용하고 reduced-motion에서는 멈춥니다.

## 2. 학습자와 감사 근거

주 페르소나는 초5~6 서윤(긴 글을 읽을 수 있지만 제목·라벨을 먼저 훑고 “왜?”와 근거를 기대하는 학습자)입니다. 375×812와 320×800은 좁은 화면 가드레일, 1280×900은 전자칠판·노트북 기준으로 확인합니다.

핵심 관찰:

1. 미션 5를 시작 화면 하단에서 선택하면 `scrollY=723.5`로 새 미션 헤더가 숨겨집니다.
2. 복원 단계에서 예측 단계로 바뀌어도 이전 스크롤이 유지되어 새 단계 제목이 viewport 밖에 놓입니다.
3. 미션 1은 `1/4` 관계만 연결해도 다음 단계가 활성화되고, 다음 화면에서 기준 전체 그래프가 노출됩니다.
4. 예측을 하나도 고르지 않아도 결과 비교로 이동하며, 결과 표에 `예측 안 함`이 반복됩니다.
5. 320px 결과 표는 열 폭이 31~88px로 압축됩니다.
6. 320px의 `건너 연결` tooltip은 `x=-52`에서 시작해 일부가 잘립니다.
7. 미션 1의 조건 문구가 복원 전 정답 경로(`풀 → 메뚜기 → 개구리 → 뱀 → 매`)를 직접 보여 줍니다.
8. 근거 문장 슬롯의 첫 라벨이 증가 사건에서도 `줄어든/없어진 생물`로 표시됩니다.

상세 근거는 [`elementary-webapp-ux-audit.md`](elementary-webapp-ux-audit.md)와 [`elementary-webapp-ux-language-audit.md`](elementary-webapp-ux-language-audit.md)에 남겼습니다.

## 3. 시각·콘텐츠·상호작용 방향

### Visual thesis

따뜻한 생태 관찰 노트의 색과 종이 분위기는 유지하되, 화면의 주인공을 장식이 아니라 현재 학습 행동으로 둡니다. 상태 전환 때 제목과 CTA가 먼저 보이고, 320px에서는 표를 세로 비교 행으로 바꾸어 한 생물의 “내 예측 → 가상 결과 → 비교”를 한 덩어리로 읽게 합니다. 색만으로 의미를 전달하지 않고 기존 라벨·선 모양·아이콘을 유지합니다.

### Content plan

`무엇을 배우는지 → 지금 할 일 → 어떻게 확인하는지` 순서로 문구를 정리합니다. `먹이사슬`과 `먹이망`을 구분하고, 실제 결과처럼 들리는 표현을 `가상 결과`로 통일합니다. 교과 용어는 제거하지 않고 쉬운 풀이를 붙입니다. 빈 근거 문장은 저장하지 않습니다.

### Interaction thesis

한 단계에서 한 가지 행동만 요구하고, 복원 완료 전에는 기준 답이 보이는 예측 단계로 이동하지 못하게 합니다. 예측 단계는 먼저 직접 연결 생물을 모두 고르게 하고, 건너 연결 예측은 선택 사항으로 남깁니다. 모든 전환은 top reset + 현재 제목 focus로 시작하며, 오답·빈 상태에는 바로 다음 회복 행동을 안내합니다.

## 4. 추천 구현 순서

### 1단계 — 학습 경계와 전환 안정화 (P1)

대상: `FoodWebRestorationApp.tsx`, `changeScenarios.ts`

- 미션 1에서 정답 화살표 경로를 제거하고 먹이망 개념 안내로 바꿉니다.
- 영향 미션은 기대 관계를 모두 맞춘 뒤에만 예측 단계로 이동하게 합니다.
- 미션/phase 변경 시 `window.scrollTo({ top: 0 })`와 현재 제목 focus를 적용합니다.

수용 기준: 같은 시작 위치에서 미션 5·복원→예측의 헤더가 0 스크롤에서 보이고, 미션 1 관계 1개 상태에서는 다음 CTA가 disabled입니다.

### 2단계 — 예측과 근거 작성의 회복성 (P2)

대상: `FoodWebRestorationApp.tsx`, `PredictionPanel.tsx`, `ResultCard.tsx`, `ChangeScenarioPanel.tsx`

- 직접 연결 생물의 예측을 모두 선택할 때까지 결과 CTA를 disabled합니다.
- 비활성 이유를 학생 말로 표시하고, 건너 연결 예측은 optional로 안내합니다.
- `실제 결과`를 `가상 결과`로 고치고, 예측 화면도 미션 기준 먹이망임을 명시합니다.
- 증가/감소/사라짐 사건에 맞춰 근거 슬롯 라벨을 동적으로 바꿉니다.
- 빈 슬롯에서는 문장을 저장하지 않도록 추가 버튼과 안내를 정리합니다.
- 결과의 사건 대상은 `사건에서 정함`, 미선택 예측은 `아직 선택 안 함`으로 구분합니다.

수용 기준: 직접 예측을 하나도 선택하지 않은 상태에서 결과로 갈 수 없고, 모든 슬롯을 채운 문장만 저장되며, 실제/가상 표현이 상태별로 일관됩니다.

### 3단계 — 모바일 결과·용어 도움말·메타데이터 (P2)

대상: `ResultCard.tsx`, `TermTip.tsx`, `OrganismCard.tsx`, `FoodWebCanvas.tsx`, CSS

- 320/375px 결과 표를 생물별 세로 비교 행으로 표시합니다.
- 모바일 tooltip이 viewport 안에 놓이도록 기준점을 조정합니다.
- 카드의 `수준: 거리 n`을 `영향 거리: n단계`로 명확히 바꿉니다.
- 모바일 핵심 `연결 확인`과 시작 CTA에 `gi-pulse`를 적용합니다.

수용 기준: 320/375px에서 표·tooltip·CTA가 잘리지 않고, `scrollWidth <= clientWidth + 1`이며, reduced-motion에서 펄스가 중단됩니다.

### 4단계 — 테스트·기록

대상: `e2e/food-web-restoration.spec.ts`, 단위 테스트, `src/data/updateHistory.ts`, 표준 work 문서

- 복원 게이트와 예측 게이트를 E2E로 고정합니다.
- 같은 학습자 시나리오를 320/375/1280px에서 재실행합니다.
- 단위 테스트·typecheck·Pages build·E2E·diff check를 실행합니다.
- 2026-08-31 개선 기록을 업데이트 내역에 추가합니다.

## 5. 시뮬레이션·시각자료 결정

- 시뮬레이션 결정: `not-needed`. 현재는 시간 흐름·연속 변수·Canvas/WebGL이 아니라 고정 그래프 관계를 해석하는 활동입니다.
- `pause`·`step`·seed는 N/A입니다. 기존 결정적 영향 엔진과 DOM/SVG를 검증합니다.
- 이미지 결정: `no-image-needed`. 이모지 카드·SVG 선·텍스트 목록이 관계와 다음 행동을 직접 전달하며, 새 생성 그림은 학습 정보를 추가하지 않습니다. 생성 이미지로 과학적 정답·수치·관계를 표현하지 않습니다.

## 6. 완료 게이트

- P0와 해결되지 않은 P1이 0개입니다.
- 핵심 관계 복원 전에는 기준 답이 다음 단계에서 노출되지 않습니다.
- 직접 예측 없이 결과로 건너뛸 수 없습니다.
- 320/375/1280px에서 핵심 경로와 결과 비교가 읽히고 가로 잘림이 없습니다.
- 정답·오답·빈 근거·완료·다음 행동 문구가 실제 상태에 표시됩니다.
- 키보드로 핵심 경로가 가능하고 포커스가 보입니다. VoiceOver는 평가하지 않습니다.
- 단위 테스트·typecheck·build·E2E·console 검사가 통과합니다.
- 앱 화면에 업데이트 내역 버튼과 2026-08-31 개선 기록이 있습니다.

## 7. 구현 완료 요약

- P1 전환 안정화: 미션·단계가 바뀔 때 문서 상단으로 이동하고 현재 미션 제목에 초점을 보냅니다. 영향 미션은 기대 관계를 모두 찾기 전에는 예측 단계로 이동하지 않습니다.
- P2 학습 경계: 바로 연결된 생물의 예측을 모두 고르기 전에는 결과 비교로 이동하지 않으며, 근거 문장은 빈칸이 남아 있으면 저장할 수 없습니다.
- P2 읽기성: 가상 결과 표현, 사건 대상/미선택 예측 라벨, 동적 근거 슬롯 라벨, 영향 거리 메타데이터를 정리했습니다.
- P2 모바일: 결과 표를 생물별 세로 비교 카드로 재배치하고, 용어 도움말을 실제 버튼 위치 기준으로 viewport 안에 배치했습니다. 모바일 핵심 연결 확인과 시작 CTA에는 `gi-pulse`를 적용했습니다.
- 회귀 고정: 2개 Playwright 학습자 시나리오에 복원·예측 게이트, 결과 표, 용어 도움말, 모바일 전환을 추가했습니다. 포트 충돌을 피할 수 있도록 `PLAYWRIGHT_PORT` 설정도 지원합니다.
