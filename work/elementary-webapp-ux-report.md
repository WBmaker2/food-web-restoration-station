# 먹이망 연결 복원소 교육용 웹앱 개선 보고서

## 결론

실제 공개 화면과 초등 5~6학년 학습자 흐름을 기준으로 점검한 뒤, 정답 노출·단계 건너뛰기·긴 페이지 전환·모바일 읽기성 문제를 추천 순서대로 개선했습니다. 해결되지 않은 P0/P1은 0개입니다.

이번 작업은 소스·문서·검증 범위로 한정했습니다. 커밋·푸시·배포·HVC 등록은 이번 요청에서 실행하지 않았으므로 공개 주소는 변경 전 배포본을 가리킵니다.

## 적용한 개선

| 분야 | 문제 | 적용한 개선 |
|---|---|---|
| 학습 경계 | 미션 1이 정답 화살표 경로를 미리 보여 줌 | `풀 → 메뚜기 → 개구리 → 뱀 → 매` 문구를 먹이망 형성 안내로 교체 |
| 학습 경계 | 관계 1개만 연결해도 예측 단계로 이동 | 기대 관계를 모두 찾을 때까지 다음 CTA disabled + 남은 행동 안내 |
| 학습 경계 | 직접 예측 없이 결과 비교 가능 | 바로 연결된 생물의 예측을 모두 선택할 때까지 결과 CTA disabled |
| 화면 전환 | 긴 시작 화면에서 미션을 고르면 새 헤더가 숨겨짐 | 미션·단계 변경 때 스크롤을 상단으로 이동하고 현재 제목에 초점 |
| 콘텐츠 | `실제 결과`, `연결한 관계` 표현이 모델 경계를 흐림 | `가상 결과`, `이 미션의 먹이망`으로 정리 |
| 콘텐츠 | 증가 사건에도 `줄어든/없어진 생물` 라벨 노출 | 증가·감소·사라짐 사건에 따라 근거 슬롯 라벨 동적 변경 |
| 콘텐츠 | 빈칸 근거 문장이 저장됨 | 모든 선택 칸을 채우기 전 `문장 추가` disabled |
| 결과 UI | 320px 5열 표가 지나치게 압축됨 | 의미 있는 `data-label`을 사용해 생물별 세로 비교 카드로 재배치 |
| 결과 UI | 사건 대상이 `예측 안 함`으로 표시됨 | `사건에서 정함`과 `아직 선택 안 함`을 분리 |
| 용어 UI | 모바일 도움말이 화면 밖으로 잘림 | 실제 버튼·말풍선 크기로 viewport 안 위치를 계산하고 스크롤/리사이즈에 대응 |
| 메타데이터 | `수준: 거리 1`처럼 의미가 섞임 | `meta` prop과 `영향 거리: 1단계` 라벨로 분리 |
| 행동 위계 | 모바일 `연결 확인`·시작 CTA가 덜 눈에 띔 | 핵심 단계 버튼에 `gi-pulse` 적용, reduced-motion에서는 유지해서 멈춤 |
| 테스트 구성 | 4173 포트 충돌 시 E2E 실행 불가 | `PLAYWRIGHT_PORT`로 격리 포트를 지정할 수 있게 개선 |

## 분야별 점검 결과

### 코드·구성

- `FoodWebRestorationApp`이 복원 완료와 직접 예측 완료를 각각 계산해 화면 단계 경계를 단일 컴포넌트에서 명확히 관리합니다.
- `TermTip`은 데스크톱의 기존 배치를 유지하면서 모바일에서만 실제 viewport 위치를 계산합니다.
- 결과 표는 HTML table 의미를 유지하고, 좁은 화면에서만 시각적 카드 레이아웃으로 바꿉니다.
- 앱 소스 파일 중 500줄 이상인 파일은 없습니다.
- 서버·로그인·개인정보 저장·외부 폰트·새 런타임 의존성은 추가하지 않았습니다.

### 학습 내용·문구

- `먹이사슬`과 `먹이망`을 “여러 줄이 연결되어 망이 된다”는 흐름으로 구분했습니다.
- 가상 모델을 실제 생태계 측정 결과로 오해하지 않도록 `가상 결과`를 사용했습니다.
- 복원 전 정답을 노출하지 않고, 관계를 모두 찾은 뒤 기준 먹이망을 보게 했습니다.
- 근거 문장 선택은 선택 사항으로 유지하되, 저장되는 문장은 빈칸 없는 문장만 허용했습니다.
- 생물 관계와 단순화된 영향 규칙은 실제 수업 전 교사·교과 검토가 필요합니다.

### 디자인·UI

- 기존의 따뜻한 생태 관찰 노트 톤과 토큰 구조를 유지했습니다.
- 새 화면이 열릴 때 제목·현재 단계·다음 행동 순서가 먼저 보이도록 했습니다.
- 결과 비교는 작은 화면에서 한 생물씩 `거리 → 내 예측 → 가상 결과 → 비교`로 읽히게 했습니다.
- 색만으로 의미를 전달하지 않고 기존 아이콘·역할 라벨·선 모양을 유지했습니다.
- 새 이미지 생성은 호출하지 않았습니다. 이 앱의 핵심 시각 정보는 정답을 대신하면 안 되는 관계 데이터와 SVG/DOM이므로, 장식용 이미지를 추가하지 않는 것이 학습·권리·유지보수 측면에서 적절하다고 판단했습니다.

### 접근성·검증

- 미션/단계 전환 시 제목에 programmatic focus를 보내 키보드 사용자의 위치를 보존했습니다.
- 중요한 CTA에는 기존 `gi-pulse`와 reduced-motion 중단 규칙을 적용했습니다.
- 320px tooltip·결과 표와 375px 단계형 연결을 E2E로 확인했습니다.
- VoiceOver 구현·검증은 요청 범위에서 제외했습니다.

## 검증 증거

| 검사 | 결과 |
|---|---|
| `npm run typecheck` | 통과 |
| `npm test -- --run` | 6개 파일, 55개 테스트 통과 |
| `npm run build:pages` | 통과 |
| `git diff --check` | 통과 |
| Playwright 학습자 흐름 | 격리한 4174 포트에서 2개 시나리오 통과 |
| 모바일 가로 폭 | 320px/375px 흐름에서 `scrollWidth <= clientWidth + 1` 확인 |
| 320px 결과 표 | 행 카드와 `data-label` 확인 |
| 320px 용어 도움말 | viewport 좌우 경계 안에 위치 확인 |
| 정적 문구 점검 | 기존 정답 화살표 문구·`예측 안 함` 실제 표시 제거 확인 |

최종 소스 기준 실제 로컬 브라우저 readback은 다음과 같습니다: 복원 1/4 CTA `disabled=true`, 빈 근거 문장 추가 `disabled=true`, 직접 예측 전 결과 CTA `disabled=true`, 320px 결과 문서 폭 `305/305`, tooltip box `x=12, width=296`, 미션 5 진입 후 `scrollY=0`, 제목이 viewport에 표시됨, 375px 단계형 연결과 캔버스 숨김이 정상입니다. 앱 흐름 중 수집한 console error는 0건이었습니다.

공식 설정 재실행은 macOS Chromium이 브라우저 시작 단계에서 `MachPortRendezvous ... Permission denied`로 종료되어 추가 진행하지 않았습니다. 앞선 동일 코드의 격리 실행은 2개 모두 통과했으며, 이 오류는 앱 assertion 실패가 아닌 로컬 Chromium 실행 환경 오류입니다.
