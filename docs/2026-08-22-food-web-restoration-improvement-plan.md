기존 [`2026-07-27-food-web-restoration-station-mvp.md`](../2026-07-27-food-web-restoration-station-mvp.md)는 초기 MVP 설계 기록으로 보존합니다. 이 문서는 현재 저장소의 실제 동작과 브라우저 감사 결과를 기준으로 한 실행 계획입니다.

## 1. 목표

1. 학생의 올바른 연결과 예측이 정확한 피드백으로 이어지도록 상태·판정 로직을 안정화합니다.
2. 계획서의 학습 계약과 실제 미션·상호작용을 일치시킵니다.
3. 데스크톱과 모바일에서 한 번에 이해되는 단일 학습 흐름을 제공합니다.
4. 중요한 진행 버튼, 키보드, 화면 낭독기, 모션 줄이기, 터치 영역을 교육용 수준으로 정리합니다.
5. CSS·문서·폰트·CI·E2E를 유지 가능한 구조로 정리합니다.

## 2. 구현 원칙

- 학생이 복원한 관계와 미션이 제공하는 기준 관계를 분리합니다.
- 정답을 미리 노출하지 않고, 단서 해석과 선택 결과를 통해 피드백을 제공합니다.
- 화면 크기마다 상호작용 방식을 하나만 노출합니다.
- 상태 변화가 있는 기능은 단위 또는 컴포넌트 회귀 테스트를 함께 추가합니다.
- 중요한 진행 버튼은 `gi-pulse` 계열 강조를 사용하되 reduced motion에서는 정지합니다.
- 외부 네트워크가 없어도 핵심 학습 흐름이 동작하도록 폰트 의존성을 줄입니다.
- 기존 MVP 문서와 현재 상태를 섞지 않고, 변경 기록은 실제 구현 날짜와 함께 남깁니다.

## 3. 시각·콘텐츠·상호작용 기준

### 시각적 방향

따뜻한 생태 관찰 노트의 분위기는 유지하되, 여러 겹의 카드·그림자·그라데이션을 줄이고 먹이망 그래프와 현재 행동을 화면의 중심으로 둡니다.

### 콘텐츠 구조

```text
짧은 안내와 시작
  → 현재 미션의 사건·조건
  → 한 가지 방식의 관계 복원
  → 변화 예측과 근거 작성
  → 결과 비교·수정
```

### 상호작용 방식

- 데스크톱/태블릿: 생물 카드 두 장을 차례로 선택해 관계를 연결합니다.
- 휴대폰: `먹히는 생물 선택 → 먹는 생물 선택 → 연결 확인` 단계형 흐름만 제공합니다.
- 단서 문장은 관계를 추론하는 데 사용하며, 확인 전 정답 화살표는 표시하지 않습니다.
- 오답 선택지에는 역방향·분해자·무관한 관계를 일부 포함해 근거 중심 피드백이 실제로 작동하게 합니다.

## 4. 단계별 실행 계획

### 1단계 — 학습 오류와 상태 흐름 안정화

대상 파일:

- `src/features/food-web-restoration/useFoodWebState.ts`
- `src/features/food-web-restoration/FoodWebRestorationApp.tsx`
- `src/data/changeScenarios.ts`
- `src/lib/influenceEngine.ts`
- 관련 테스트 파일

작업:

- 연결 성공·실패 결과를 상태 업데이트와 분리해 즉시 정확한 피드백을 표시합니다.
- `resetMissionState()`로 링크·예측·근거·단계 피드백을 함께 초기화합니다.
- 빈 그래프에만 기준 관계를 대체로 사용하는 현재 로직을 제거하고, 영향 계산에 기준 관계와 학생 관계를 명시적으로 전달합니다.
- 미션 0은 화살표 방향 훈련으로 동작하도록 사건 예측 단계를 분리하거나, 실제 구현을 반영하도록 미션 콘텐츠를 명확히 수정합니다.
- 미션 1의 제목·목표·관계 구조를 일치시킵니다.
- 예측 단계에서 아직 결과가 없는 비교 패널이 빈 값으로 보이지 않게 합니다.

완료 조건:

- 올바른 관계 연결 시 성공 피드백이 표시됩니다.
- 부분 복원 상태에서도 미션의 고정 조건과 대체 먹이 규칙이 일관됩니다.
- 다시하기 후 이전 예측과 근거가 남지 않습니다.
- 미션 0·1의 제목, 사건, 단계가 학습 목표와 일치합니다.

### 2단계 — 관계 복원 상호작용과 학습 피드백 개선

대상 파일:

- `RelationPrompt.tsx`
- `FoodWebCanvas.tsx`
- `OrganismCard.tsx`
- `accessibilityLabels.ts`
- 관계 데이터 및 피드백 데이터

작업:

- 화면 크기에 따라 단서 카드 방식과 단계형 방식을 분리합니다.
- 데스크톱 카드 선택 기능을 실제 앱에 연결합니다.
- 단서 카드에서 확인 전 `풀 → 메뚜기` 정답 표시를 제거합니다.
- 정답 관계뿐 아니라 교육적으로 의미 있는 오답 후보를 구성합니다.
- 역방향, 중복, 분해자, 무관 관계의 피드백을 실제 UI에서 확인할 수 있게 합니다.
- 결과 근거를 단순한 일반 문장이 아니라 연결 경로와 미션 조건에 맞게 표시합니다.

완료 조건:

- 데스크톱과 모바일에서 중복된 조작 UI가 보이지 않습니다.
- 키보드만으로 생물 카드 선택·연결·삭제가 가능합니다.
- 학생이 단서 내용을 읽고 관계를 추론해야 하며, 정답이 초기 화면에 노출되지 않습니다.
- 오답 피드백이 실제로 도달 가능한 상태입니다.

### 3단계 — 반응형·접근성·진행 강조·디자인 정리

대상 파일:

- `src/styles/food-web-restoration.css`
- `src/styles/a11y.css`
- 새로 분리할 스타일 파일
- `index.html`
- 관련 컴포넌트

작업:

- 500줄을 넘은 CSS를 토큰·기본·인트로·미션·그래프·결과·반응형 영역으로 분리합니다.
- 모바일 그래프를 단계형 흐름에 맞춰 숨기거나 실제 화면 폭에 맞게 계산합니다.
- 캔버스에 가로 이동이 필요할 때 명시적인 안내를 제공합니다.
- 44px 이상 터치 영역, `<main>`, 건너뛰기 링크, 화면 낭독기 상태, 영향 거리 라벨을 보완합니다.
- 주요 다음 단계 버튼에 `gi-pulse`를 적용하고 reduced motion에서는 비활성화합니다.
- 외부 Google Fonts 의존성을 줄이고 favicon·theme-color·기본 공유 메타 정보를 추가합니다.
- 장식적 카드와 그라데이션을 줄여 그래프 중심의 시각 위계를 만듭니다.

완료 조건:

- 375px, 768px, 1280px에서 가로 잘림이 없습니다.
- 주요 버튼·업데이트 내역·체크박스 라벨을 터치하기 쉽습니다.
- reduced motion과 키보드 흐름이 유지됩니다.
- 브라우저 콘솔에 favicon 및 정적 자산 오류가 없습니다.
